# Завдання 37 · Fiche yacht: перегляд фото на весь екран (lightbox)

Прочитай CLAUDE.md. Кроки **A → C**, після кожного `npm run format` + `npm run build`, короткий звіт і стоп.

Навіщо: на сторінці яхти людина хоче роздивитись каюту чи план палуби ближче. Клік по фото → фото на весь екран, гортати між фото, закрити.

## A · Компонент `src/components/ui/Lightbox.astro` + `src/scripts/lightbox.ts`

Один спільний (знадобиться і для статей Journal).

- Розмітка: `<dialog class="lightbox" aria-label="Galerie photos">` (`showModal()`), фон — `rgb(14 14 14 / .96)` на весь екран, без радіуса, `::backdrop` такий самий.
- **Вміст:**
  - фото по центру: `max-width: 100%; max-height: calc(100svh - 160px); object-fit: contain` — видно повністю, без обрізання;
  - зверху праворуч — **хрестик** (44 × 44, `aria-label="Fermer"`), зліва зверху — лічильник «3 / 6» (eyebrow, `--color-text-2`);
  - знизу — підпис: назва кімнати (Body M) + палуба (Body S, secondary), як під карткою;
  - по боках — **стрілки** (той самий `Button / Arrow` 88 × 88, як у «À bord»; mobile — без стрілок, лише свайп).
- **Великий файл**: у лайтбоксі — версія до **2000 px** (`getImage()` на збірці, шлях у `data-full` на мініатюрі), щоб на великому екрані було чітко. Вантажимо лише при відкритті (`loading` при показі), сусіднє фото — заздалегідь (`new Image()`).
- **Керування:** ← / → — сусіднє фото (по колу), **Esc** — закрити, клік по фону (не по фото) — закрити; свайп вліво / вправо на тачскріні; на mobile — масштаб пальцями (`touch-action: pinch-zoom` на фото).
- **Збільшення на desktop:** клік по фото → ×2 у точці кліку (`transform: scale(2)`, `transform-origin` = точка), рух мишки — переміщення, повторний клік — назад. Курсор `zoom-in` / `zoom-out`.
- **Анімація:** відкриття — плавна поява 200 ms (opacity + scale .98 → 1), зміна фото — crossfade 200 ms; `prefers-reduced-motion` — без руху.
- **Доступність:** фокус при відкритті — на хрестик, Tab ходить лише всередині, після закриття — назад на фото, з якого відкрили; `alt` у лайтбоксі = підпис фото; сторінка під ним не прокручується (`overflow: hidden` на `html` через клас).
- Без inline-стилів (CSP): `transform-origin` — через `style.setProperty` у скрипті.

## B · Де вмикаємо

На **Fiche yacht** одна спільна галерея (гортаються всі фото сторінки по порядку):

1. «Le yacht» — головне фото + 3 фото;
2. «Résumé» — фото яхти біля причалу;
3. «À bord» — усі картки каруселі;
4. «Plan de pont» — **плани палуб** (на mobile особливо потрібно — дрібні деталі), підпис — назва палуби.

Кожне фото — `<button class="lb-trigger" aria-label="Agrandir : Suite du propriétaire">` навколо зображення (не посилання).
Курсор `zoom-in`, при наведенні — маленька іконка «+» / лупа в правому нижньому куті фото (коло 40 px, фон `rgb(14 14 14 / .6)`, 200 ms поява).
У «À bord» перетягування мишкою не має відкривати лайтбокс: якщо зрушили > 6 px — це прокрутка, не клік (`drag-scroll.ts` уже це знає — перевір).

## C · Дрібне виправлення в «À bord»

Після кліку по стрілках навколо стрічки видно **білі лінії зверху і знизу** — це рамка фокусу `.yint__track:focus-visible`.
Залиш її лише для клавіатури: фокус на стрічку не переводити при кліку по стрілках (кнопки самі тримають фокус), або `outline` лише коли фокус прийшов з Tab.

## Перевірка

- Клік по будь-якому фото / плану → на весь екран, видно повністю; ← → гортають всі фото сторінки; Esc / хрестик / фон — закривають, фокус повертається.
- Desktop: клік по фото — ×2, ще клік — назад. Mobile: свайп і масштаб пальцями.
- Перетягування «À bord» не відкриває лайтбокс. Білих ліній після кліку по стрілках немає.
- Немає помилок CSP, `npm run build` зелений.
