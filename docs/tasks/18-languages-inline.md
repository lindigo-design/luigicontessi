# Завдання 18 · Мови в шапці — в один рядок «FR EN IT» (без випадного списку)

Прочитай CLAUDE.md. Один етап: зроби лише це, потім звіт і стоп.
Figma: компонент **Header / Desktop** (`131:499`) → `Right` → «Langues (FR · EN · IT)».

## Проблема

Зараз у шапці видно лише «FR», а інші мови ховаються у випадному списку після кліку.
Людина бачить одну мову і думає, що сайт тільки французькою. Італійці й англомовні — велика частина
аудиторії Luigi, вони не мають шукати перемикач.

## Як має бути

```
☰ MENU                    LUIGI CONTESSI                    PRIVILÈGES   FR  EN  IT   [PANIER (0)]
```

- Три мови завжди видно в один рядок, проміжок **16 px**, стиль Label/Nav (13 px, великі літери, `letter-spacing: .08em`).
- **Поточна** мова — `--color-text` (біла), `aria-current="true"`, не посилання (або посилання на саму себе без hover).
- **Інші** — `--color-text-2` (сірі), hover → `--color-text`.
- **Без підкреслення** (на відміну від «PRIVILÈGES»): три коди поруч — це перемикач, а не текстові посилання;
  підкреслення трьох коротких слів поспіль виглядає як помилка.
- Кожна мова — `<a href={switchLocale(path, code)} hreflang lang>` — **та сама сторінка** іншою мовою.
- Для читалок: група `<nav aria-label={t('lang.label')}>` і повна назва мови в `aria-label` («English», «Italiano»),
  на екрані — лише коди.
- Відступ між «PRIVILÈGES» і групою мов — 12 px (як у Figma, `Right` gap 12).
- Прибрати випадний список (`<details>` / кнопку з меню мов) з шапки повністю.
- Використати вже наявний `LanguageSwitcher.astro` (варіант `nav`) — він рендерить саме такий рядок.

## Mobile (< 768)

У мобільній шапці місця мало (логотип + кошик + бургер), тому мови там не показуємо,
**але** у відкритому мобільному меню рядок «FR EN IT» стоїть **нагорі**, одразу під логотипом
(а не лише внизу, як зараз) — щоб його було видно без прокрутки меню.

## Те саме в інших місцях

Футер і низ меню на весь екран уже показують «FR EN IT» рядком — перевір, що стилі однакові
(той самий компонент, поточна біла, інші сірі, без підкреслення).

## Що НЕ чіпати

«PRIVILÈGES», «MENU», логотип, кошик; логіку `switchLocale`.

## Перевірка

1. `npm run format`, `npm run build`.
2. Desktop 1440: у шапці «FR EN IT», FR біла, EN/IT сірі; клік по EN → та сама сторінка `/en/…`, тепер біла EN.
3. Сторінка товару / коду / статті: перемикач веде на той самий товар/статтю іншою мовою.
4. Tab: кожна мова отримує фокус; читалка вимовляє «English», «Italiano».
5. Mobile: мови видно одразу при відкритті меню.
6. Звіт + список файлів. Стоп.
