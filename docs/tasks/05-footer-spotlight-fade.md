# Завдання 05 · CONTESSI у футері: поза «прожектором» літери зникають (як у Bugatti)

Прочитай CLAUDE.md. Один етап: зроби лише це, потім звіт і стоп.
Стосується лише напису CONTESSI у `src/components/sections/Footer.astro` (завдання 02).

## Що не так зараз

Напис складається з двох шарів:

- `.ghost__base` — завжди видимий (`--color-ghost` #1A1A1A);
- `.ghost__light` — світлий шар із зерном під курсором.

Через базовий шар усе слово видно завжди, а курсор лише підсвічує частину.

## Як у Bugatti (перевірено в браузері)

Шар **один**. Маска `radial-gradient(… #000 0%, transparent 60%)` діє на **весь** напис:

- під курсором літери сірі із зерном;
- чим далі від курсора — тим прозоріші;
- за межею плями — **повністю невидимі**, зливаються з фоном футера.
  Коли мишки немає, пляма стоїть у лівій верхній частині напису: видно «BUGA», праворуч слово зникає.

## Що змінити

1. **Прибрати базовий шар** `.ghost__base` з розмітки і стилів.
   Залишити один `<p class="ghost__light">CONTESSI</p>` (або перейменувати на `.ghost__text`).
   Токен `--color-ghost` більше не використовується в футері — не видаляти, він є у Figma.
2. **Маска на весь напис** (вже є на світлому шарі — лишити):
   ```css
   mask-image: radial-gradient(
     circle var(--spot-r) at var(--mx) var(--my),
     #000 0%,
     transparent 60%
   );
   ```
   Колір літер: `--color-text` з `opacity: var(--ghost-light-opacity)` (0.4) + зерно `noise.svg` — без змін.
3. **Стан без мишки** (замість «пляма за кадром»):
   - стартова позиція: `--mx: 20%; --my: 0%` — видно ліву частину слова, праворуч воно розчиняється;
   - `pointerleave` з футера → пляма плавно повертається в цю стартову точку
     (а не відлітає вгору, як зараз — інакше напис зникне зовсім).
   - Значення стартової точки — у CSS (змінні на `.ghost`), скрипт бере їх через
     `getComputedStyle`, щоб не дублювати числа в JS.
4. **Розмір плями**: `--spot-r: 40vw` (з 0.6 = 60 % у градієнті видима зона ≈ 24vw від центру,
   тобто 2–3 літери). Якщо після перевірки здається замало — 45vw.
5. **Телефони** (`hover: none`): пляма статична в центрі (`--mx: 50%; --my: 40%`), `--spot-r: 70vw`,
   щоб на вузькому екрані було видно більшу частину слова.
6. Запас зверху від смужки на літерах (`padding-top: 0.1em`, `margin-top: calc(var(--space-8) - 0.1em)`) —
   **залишити**: він тепер на єдиному шарі.

## Що НЕ чіпати

- Розмір і обрізання слова (`font-size`, `margin-bottom: -0.1em`).
- Плавність руху плями (EASE = 0.12) і логіку IntersectionObserver.
- Решту футера.

## Перевірка

1. `npm run format`, `npm run build` — без помилок і без помилок CSP.
2. Desktop 1440 без мишки над футером: зліва видно «CON…», праворуч літери поступово зникають до фону.
3. Ведеш мишкою вправо — проявляються «…SSI», а «CON» зникає; між плямою і рештою — плавний перехід,
   без різкого краю і без смужки зверху на літерах.
4. Мишка пішла з футера — пляма плавно повертається вліво-вгору.
5. Mobile 390: слово видно в центрі, краї розчиняються, нічого не рухається.
6. Звіт: що зроблено + список файлів. Стоп.
