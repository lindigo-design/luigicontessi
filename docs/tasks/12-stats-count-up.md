# Завдання 12 · Анімація цифр: «лічильник» 0 → 1,7 M+

Прочитай CLAUDE.md. Один етап: зроби лише це, потім звіт і стоп.

## Де

Усі великі цифри (стиль Desktop/Stat / Mobile/Stat):

- Головна → «À propos»: 1,7 M+ · 500+ · 30+
- Сторінка «À propos» (якщо вже зроблена) — той самий блок
- «Partenariats» → «Mon audience en chiffres»: 1,7 M+ · 4,8 % · 50 M+ · 500+

## Як має виглядати

- Коли блок з цифрами **вперше** зʼявляється на екрані (≈ 40 % видно), числа рахують від 0 до значення.
- Тривалість **1.6 с**, крива — сповільнення в кінці (`easeOutExpo`): швидко стартує і м'яко «доїжджає».
  Для люксу — спокійно, без «ігрового автомата».
- Цифри стартують одночасно, з невеликою затримкою одна за одною (0 / 120 / 240 мс).
- Анімація **один раз** за відвідування (повертаєшся скролом — числа вже стоять).
- Префікси, суфікси і формат беремо з тексту як є: «1,7 M+», «4,8 %», «500+», «30+».
  Рахується лише числова частина: `1,7` → 0,0 … 1,7 (з однією цифрою після коми, як у кінці),
  `500` → 0 … 500 (цілі). Кома/крапка — як у мові сторінки (`Intl.NumberFormat(lang)`): FR/IT «1,7», EN «1.7».

## Важливі дрібниці (щоб не «стрибало»)

1. **Ширина не змінюється під час рахунку.** Інакше «1,7 M+» штовхає сусідні цифри.
   Рішення: у кожній цифрі два шари в одній grid-клітинці:
   ```html
   <dd class="stat__value">
     <span class="stat__final" aria-hidden="true">1,7 M+</span>
     <!-- невидимий, тримає ширину -->
     <span class="stat__live" aria-hidden="true">0 M+</span>
     <!-- те, що рахує -->
     <span class="visually-hidden">1,7 M+</span>
     <!-- для читалок — одразу фінальне -->
   </dd>
   ```
   `.stat__final { visibility: hidden }`, обидва шари `grid-area: 1 / 1`.
   Плюс `font-variant-numeric: tabular-nums` (якщо Cal Sans не підтримує — нічого страшного, ширину тримає шар `final`).
2. **Без JS / з `prefers-reduced-motion`** — одразу фінальні значення, жодного руху.
   За замовчуванням у HTML стоїть **фінальне** значення; скрипт ставить 0 лише перед стартом,
   коли вже знає, що анімація буде (інакше при повільному скрипті людина побачить «0»).
3. **Читалки екрана** чують тільки фінальне число (див. розмітку), не потік «1, 2, 3…».
4. Оновлення — через `requestAnimationFrame`, текст міняти лише в `stat__live` (`textContent`).

## Код

- Новий файл `src/scripts/count-up.ts`:
  - шукає `[data-count]`, читає з `data-count` значення (`1.7`), `data-decimals` (`1`), а префікс/суфікс —
    з тексту навколо числа в фінальному значенні;
  - IntersectionObserver з `threshold: 0.4`, після старту `unobserve`;
  - `easeOutExpo = t => (t === 1 ? 1 : 1 - Math.pow(2, -10 * t))`.
- Числові значення додати в дані як окремі поля, щоб скрипт не «вгадував» з рядка:
  ```jsonc
  "stats": [
    { "value": "1,7 M+", "count": 1.7, "decimals": 1, "label": "abonnés Instagram" },
    { "value": "500+",   "count": 500,                 "label": "collaborations" },
    { "value": "30+",    "count": 30,                  "label": "pays" }
  ]
  ```
  `count` і `decimals` — необовʼязкові (Zod `optional`): якщо `count` немає — число не анімується
  (наприклад, плейсхолдер «[X] %» на Partenariats). Поля в Keystatic: «Число для анімації (необовʼязково)».
- Підключити скрипт один раз (BaseLayout), він сам знайде всі `[data-count]` на сторінці.

## Що НЕ чіпати

Розміри шрифтів, кольори, розкладку блоку цифр, тексти підписів.

## Перевірка

1. `npm run format`, `npm run build`, без помилок CSP.
2. Desktop 1440: прокрутка до «À propos» — цифри рахують за 1.6 с, нічого поруч не зсувається.
3. Повертаєшся вгору і знову вниз — анімація не повторюється.
4. EN-версія: «1.7M+» з крапкою.
5. «Зменшити рух» увімкнено — одразу фінальні числа.
6. Вимкнений JS (DevTools → Disable JavaScript) — фінальні числа, не нулі.
7. Звіт + список файлів. Стоп.
