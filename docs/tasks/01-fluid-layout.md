# Завдання 01 · Гнучка ширина: меню, футер, hero, Nouveautés

Прочитай CLAUDE.md. Це один етап: зроби лише те, що тут описано, потім зупинись і дай звіт.

Референс — bugatti.com: меню і футер на всю ширину екрана, перший екран на весь екран,
великий напис бренду внизу футера.

## Що НЕ чіпати

- Тексти (src/content, src/i18n/ui) не змінювати.
- Розміри шрифтів, кольори, затемнення фото не змінювати.
- Порядок секцій не змінювати.
- Mobile 390 px має виглядати так само, як зараз (крім висоти hero).

## Правило ширини (головне)

Зараз увесь контент обмежений 1440 px (`--container-max` у tokens.css), тому на екрані 1920 px
меню, футер і секції стоять «островом» посередині. Робимо два типи блоків:

| Тип                       | Які блоки                                                                                        | Ширина                                                                                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Bleed** (на всю ширину) | Header, Footer, Hero, трек каруселі Nouveautés                                                   | 100% екрана. Бічний відступ = `--gutter` (16 → 80 px). Без max-width.                                                                                                                   |
| **Content** (усе інше)    | About, Presse, Univers, Collection, Privilèges, Yachts (текст), Instagram, FAQ, Pour les marques | Бічний відступ `--gutter` (80 px на desktop). Контент не ширший за `--content-max: 1760px`. До 1920 px відступ рівно 80 px; на ширших екранах поля ростуть, щоб рядки не розтягувались. |

Фони секцій (bg/alt, фото Quote/Yachts/Brands) і так ідуть на всю ширину — лишити.

### Кроки

1. `src/styles/tokens.css`: замінити `--container-max: 90rem` на `--content-max: 110rem; /* 1760 */`.
   Додати `--promo-h` (висота промо-смуги: 64px mobile, 68px desktop).
2. `src/styles/container.css`:
   - `.container` → `max-width: calc(var(--content-max) + 2 * var(--gutter))`, `padding-inline: var(--gutter)`.
   - новий клас `.container--bleed` → `max-width: none`.
3. Header, Footer і Hero — використати `.container--bleed` замість `.container`.
4. Перевір, що жодна секція не має фіксованих ширин у px, які ламаються на 1920/2560
   (сітки — тільки `minmax(0, 1fr)`, фото — `width: 100%` + `aspect-ratio`).

## Header (Figma: 01 Hero → Header)

- На всю ширину: логотип притиснутий до лівого краю відступу, Partenariats / мови — до правого.
- Пункти меню (Journal… Privilèges) — по центру екрана, а не одразу після логотипа:
  сітка `grid-template-columns: 1fr auto 1fr`, ліва колонка `justify-self: start`, права `end`.
- Поведінка при прокрутці (новий файл `src/scripts/header.ts`):
  - на першому екрані — прозорий фон (як зараз);
  - після прокрутки на 80 px → фон `--color-bg`, тонка лінія знизу `--color-border`, перехід 240 ms;
  - прокрутка вниз — меню ховається вгору (`transform: translateY(-100%)`), вгору — повертається;
  - `prefers-reduced-motion` → без анімації, просто фон.
  - Header стає `position: fixed` (зараз `absolute`). На сторінках без hero додати відступ зверху `main`.
- Без скла/розмиття (backdrop-filter) — у нас суцільні поверхні.

## Hero (Figma: 01 Hero)

- Висота: `min-height: calc(100svh - var(--promo-h))` — разом з промо-смугою рівно один екран.
  Використати `svh`, не `vh` (на телефоні адресний рядок не «з'їдає» низ).
- Нижня межа: `min-height` не менше 640 px (на низьких ноутбуках текст і картки не налазять одне на одне).
- Фото — `object-fit: cover`. `object-position` уже взятий з кадрування у Figma (desktop: hero 50% 55%, Quote 50% 58%, Yachts 0% 0%) — не змінювати, лише перевірити, що на 1920 і 2560 обличчя Luigi в кадрі.
- Текст і картки — притиснуті до низу, бічний відступ `--gutter`, на 1920 px картки біля правого краю.

## Footer (Figma: 12 Footer)

- Розсилка, колонки і нижній рядок — на всю ширину з `--gutter`.
- Колонки: 4 колонки на всю ширину (`repeat(4, minmax(0, 1fr))`).
- Напис CONTESSI (`.footer__ghost`):
  - розмір від ширини екрана, щоб слово займало всю ширину між відступами:
    `font-size: calc((100vw - 2 * var(--gutter)) / 6.4)` (Boldonse: ширина слова ≈ 6.39 × кегль);
  - обрізаний знизу приблизно на третину (як BUGATTI): `margin-bottom: -0.32em`, `overflow: hidden` у футера;
  - вирівнювання по лівому краю відступу; `aria-hidden`, не виділяється.
- Перевір, що на 390 px слово теж вміщається у ширину (≈ 56 px).

## Nouveautés — на всю ширину (Figma: 04 Nouveautés)

- Заголовок секції лишається в `.container` (відступ 80 px).
- Трек каруселі — на всю ширину екрана, без бічних відступів: крайні картки обрізаються краєм екрана.
- Активна картка — завжди по центру екрана.
- Розміри карток ростуть разом з екраном:
  - мала: `clamp(15rem, 19.5vw, 22.5rem)` (240 → 280 на 1440 → 360 max);
  - активна: `clamp(18.75rem, 39vw, 45rem)` (300 → 560 на 1440 → 720 max);
  - фото малої — квадрат, активної — 560 / 680.
- Стрілки «назад / вперед» — по боках від активної картки на рівні її нижнього краю (як у Figma),
  на mobile — крапки замість стрілок (як зараз).
- Клавіатура: стрілки ← → на фокусі в каруселі гортають картки.

## Перевірка

1. `npm run format`, `npm run build` — без помилок.
2. Переглянь сторінку на ширинах **390 / 768 / 1024 / 1440 / 1920 / 2560 px**:
   - немає горизонтальної прокрутки сторінки;
   - на 1440 і 1920 бічні відступи секцій = 80 px;
   - на 2560 контент секцій не ширший за 1760 px, а меню, футер, hero і карусель — на всю ширину;
   - hero + промо-смуга = рівно висота вікна;
   - CONTESSI у футері від лівого до правого відступу, обрізаний знизу.
3. У консолі браузера немає помилок (зокрема CSP).
4. Звіт: що змінено + список файлів. Далі не йти.
