## Що зробити в `DeckPlan.astro`

1. `<Image src={d.plan} … widths={[960, 1600, 2560]} sizes="(min-width: 1024px) min(89vw, 1760px), 40rem" loading="lazy">`
   — зараз без `widths`, тож на великих екранах план мильний.
2. План заповнює рамку: `.ydeck__img { width: 100%; height: 100%; object-fit: contain; }`, рамка `aspect-ratio: 1280 / 400`, фон `--color-card` (вже так).
   Без внутрішніх відступів — поля вже є в самій картинці.
3. Mobile: як зараз — план не дрібніший за `min-width: 40rem`, гортається вбік пальцем; **додай** легку підказку справа (градієнт-маска на правому краї рамки,
   `mask-image: linear-gradient(to right, #000 85%, transparent)`), щоб було видно, що є продовження. Коли догорнули до кінця — маску прибрати (клас зі скрипта).
4. Перемикання чипами — як зараз (200 ms). Заголовок рахує палуби сам: 3 → «Trois ponts, pièce par pièce».
5. `alt`: «Aurora — Pont principal» тощо (вже так).
6. Підписи кімнат — **не** додаємо поверх картинки (поки немає даних від верфі); TODO в коді: для справжньої яхти — векторний план (SVG) з General Arrangement верфі.
