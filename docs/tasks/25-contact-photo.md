Figma: **Contact** — desktop фрейм «08 Yachts» `161:3054`, mobile `162:579` (між «01 Contact» і футером).

Фото вже в проєкті: `src/assets/img/contact/yacht.jpg` (2560 × 1429, яхта з дрона на заході сонця).

## Що зробити

1. Новий компонент `src/components/sections/contact/ContactPhoto.astro`, на сторінці `contact.astro` — **після** `ContactMain`, перед футером.
2. Фото на всю ширину екрана, без бокових відступів і радіуса, `<Image widths={[768, 1280, 1920, 2560]} sizes="100vw" loading="lazy">`,
   `alt=""` + `aria-hidden="true"` (декоративне, як фото в Privilèges).
3. Висота: desktop **800** при 1440 → fluid `clamp(27.5rem, 55.5vw, 60rem)` (440 на mobile, 800 на 1440, не вище 960);
   `object-fit: cover`. Кадр: desktop `object-position: 50% 50%`, < 768 — **`86% 50%`** (щоб яхта була в кадрі, як у Figma mobile).
4. **Градієнт поверх фото** (`::after` на обгортці, колір `--color-bg` #0E0E0E), згори вниз — плавно виходить з тла сторінки і так само плавно йде у футер:

| позиція | непрозорість |
| ------- | ------------ |
| 0 %     | 100 %        |
| 6 %     | 75 %         |
| 20 %    | 0            |
| 60 %    | 0            |
| 80 %    | 55 %         |
| 93 %    | 90 %         |
| 100 %   | 100 %        |

Через `linear-gradient(to bottom, rgb(14 14 14 / 1) 0%, … )`. Без inline-стилів (CSP) — усе в `<style>` компонента. 5. Між фото і футером — **без відступу і без лінії**: низ фото = колір футера, шов не видно.
Якщо в футера є верхня лінія `border-top` — на цій сторінці її не має бути (клас-модифікатор на футері, наприклад `footer--seamless`, через пропс у BaseLayout). 6. Нижній відступ секції «01 Contact» — зменшити до 64 (desktop) / 40 (mobile): верхній градієнт фото сам дає «повітря». 7. Легкий паралакс **не** робимо (рух на сторінці форми відволікає).

## Перевірка

- 390 / 768 / 1440 / 1920: немає видимої межі ні зверху фото, ні між фото і футером; яхта в кадрі на 390.
- Lighthouse: фото не впливає на LCP (lazy, нижче першого екрана).
- Немає помилок CSP, `npm run build` зелений.
