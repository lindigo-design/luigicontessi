# Завдання 13 · Hover для карток без фото: легкий зум + підсвітка за курсором

Прочитай CLAUDE.md. Один етап: зроби лише це, потім звіт і стоп.
Виконувати після завдання 03 (там зум фото в картках).

## Де

Картки на темній плашці `--color-card` **без фото**, які ведуть кудись:

- **Card / Presse** — головна «Ils parlent de moi», сторінка «Presse», список преси на «Partenariats»;
- надалі — будь-яка така ж текстова картка-посилання (Card / Article без фото тощо).

**Не застосовувати** до Card / Code partenaire: у ній дві різні дії («Copier le code» і «Voir la marque»),
вся картка не є одним посиланням — зум підказував би неправильне.

## Як має виглядати

1. **Уся картка — одне посилання.** Зараз клікабельне лише «Lire l'article →».
   Робимо «розтягнуте» посилання: головне посилання в картці отримує `::after { content: ''; position: absolute; inset: 0 }`,
   картка — `position: relative`. Клік будь-де на картці = перехід. Текст «Lire l'article / Regarder / Écouter»
   лишається видимим посиланням (для читалок і Tab — одна точка фокусу на картку).
2. **Легкий зум:** уся картка `transform: scale(1.02)` за `var(--zoom-dur)` (300 мс) з `var(--zoom-ease)` —
   ті самі токени, що в завданні 03. Сусідні картки не рухаються (transform не змінює розкладку).
3. **Підсвітка за курсором** (той самий прийом, що «прожектор» CONTESSI у футері, тільки дуже мʼякий):
   - поверх фону картки — м'яка кругла пляма світла там, де курсор:
     ```css
     .hover-card::before {
       content: '';
       position: absolute;
       inset: 0;
       border-radius: inherit;
       pointer-events: none;
       background: radial-gradient(
         circle 320px at var(--mx, 50%) var(--my, 50%),
         rgb(237 234 228 / 0.07),
         transparent 70%
       );
       opacity: 0;
       transition: opacity var(--zoom-dur) var(--zoom-ease);
     }
     .hover-card:hover::before {
       opacity: 1;
     }
     ```
   - JS (`src/scripts/hover-card.ts`): на `pointermove` записує координати курсора відносно картки
     в `--mx` / `--my` через `style.setProperty` (CSSOM — дозволено нашою CSP). Без плавного «доганяння» —
     пляма просто під курсором (на картці це виглядає природніше, ніж у футері).
   - Без JS або без руху мишки — пляма в центрі (`50% 50%`), тобто просто рівномірно світліша картка.
4. **Тонка рамка при наведенні:** `box-shadow: inset 0 0 0 1px var(--color-border)` → на hover
   `inset 0 0 0 1px rgb(237 234 228 / 0.16)` — краї картки «проявляються».
5. **Стрілка** в колі заливається червоним — як уже працює на Link Accent (`.hover-card:hover .arrow`).
6. Те саме при фокусі з клавіатури: `.hover-card:focus-within` = стан hover (пляма — по центру),
   плюс наш червоний контур фокусу навколо всієї картки (`outline` на картці, не на тексті).

## Обмеження

- Лише на пристроях з мишкою: усе обгорнути в `@media (hover: hover) and (pointer: fine)`.
  На телефоні — без зуму і плями (після дотику нічого не «залипає»).
- `prefers-reduced-motion: reduce` — без зуму, підсвітка лишається (вона не рух).
- Нові токени (tokens.css): `--card-glow: rgb(237 234 228 / 0.07)`, `--card-edge-hover: rgb(237 234 228 / 0.16)`,
  `--card-scale: 1.02`.
- Клас `.hover-card` і скрипт — спільні, у `components.css` / `scripts/`, не копіювати в кожну секцію.

## Що НЕ чіпати

Розміри, відступи, тексти карток; Card / Code partenaire; зум фото з завдання 03.
