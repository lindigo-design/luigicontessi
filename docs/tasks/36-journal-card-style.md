Навіщо: на темному фоні картки зливались одна з одною, і не було явної дії. Тепер вони як картки «Presse» на головній — одна родина карток на сайті.

## Вигляд картки (сітка «Articles»)

- Картка: фон `--color-card`, радіус 4, padding **28** (mobile 20), проміжок між елементами **20** (mobile 16).
- Порядок: фото (`aspect-ratio: 4 / 3` всередині padding, радіус 4) → мета «Automobiles · 5 min · Partenariat» (eyebrow, muted) → заголовок H3 28 → excerpt Body S secondary →
  **Link Accent «Lire l’article»** з колом-стрілкою (правило: червоне посилання — завжди зі стрілкою). Переклади: «Read the article» / «Leggi l’articolo».
- Висота карток у ряду **однакова**: картка `display: flex; flex-direction: column; height: 100%`, excerpt `flex: 1` — кнопка завжди внизу на одній лінії.
- Hover — як у картки преси: світло за курсором (`hover-card`, завдання 13) + легкий зум фото (`zoom-card`, лише фото).
- Уся картка клікабельна одним посиланням (як у пресі: кнопка — головне посилання, решта — `::after` на всю картку або обгортка `<a>`, без вкладених посилань); фокус — на кнопці.
- Поки сторінки статті немає — заглушка з `articleHref()` (завдання 31): кнопка `aria-disabled`, «Article bientôt disponible».

## «À la une»

Без змін (велике фото + текст без картки) — це головна стаття, вона й має відрізнятися.

- Наведення: світло + зум фото; Tab доходить до кожної кнопки.
