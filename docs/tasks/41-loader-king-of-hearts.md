# Завдання 41 · Loader-монограма K♥ для повільного інтернету

Прочитай CLAUDE.md. Кроки **A → C**, після кожного `npm run format` + `npm run build`, короткий звіт і стоп.

Figma: сторінка **États** — «Loader — Desktop 1440» `202:657`, «Loader — Mobile 390» `202:677`, розкадровка «Loader — Animation (étapes)» `204:683`.
Ідея: логотип Luigi — «K» і серце (король червей). Подаємо його як **монограму будинку моди**: K промальовується пером, серце наповнюється і робить один удар.
**Без** гральної карти, куточків, перевертання й сяйва — щоб не нагадувало казино.

## Головні правила (щоб loader не шкодив)

- **Швидкий інтернет — loader не видно.** Показуємо лише якщо сторінка не готова через **400 ms** після старту.
- **Лише перше відкриття сайту в сесії** (`sessionStorage['lc-loaded']`, try/catch). Переходи між сторінками — без loader.
- HTML сторінки вже під loader-ом (пошуковики й читалки бачать усе); накладка `aria-hidden="true"`, для читалки — `role="status"` «Chargement…», зникає разом із нею.
- **Без JS — loader-а немає** (створюється скриптом).
- **Максимум 4 с**, потім ховається за будь-якої умови.
- `prefers-reduced-motion` → без промальовки й удару: готовий логотип + смужка.
- Сторінка 404 / 500 — без loader-а.

## A · Вигляд (`src/components/ui/Loader.astro` + `src/scripts/loader.ts`, без inline — CSP)

- На весь екран, фон `--color-bg`, по центру стовпчиком, проміжок 40.
- **Монограма** — inline SVG із `src/assets/brand/corner-k-tall.svg` (дві фігури: `K` і серце), висота **120** (mobile 96), колір `--color-red`.
- Під нею **смужка** 160 × 2, фон `--color-border`, заповнення `--color-red` (`transform: scaleX()`), і «LUIGI CONTESSI» (12, `letter-spacing: .2em`, `--color-text-2`).

## B · Анімація (як у розкадровці `204:683`)

1. **0–0,8 с — K промальовується:** контур K лінією 1.5 px (`fill: transparent; stroke: currentColor`), `stroke-dasharray` = довжина шляху (`getTotalLength()`), `stroke-dashoffset` → 0, `ease-in-out`.
2. **0,8–1,3 с — K заповнюється, серце промальовується:** `fill-opacity` K 0 → 1 (300 ms), контур серця тим самим способом.
3. **1,3–1,8 с — серце заповнюється і робить один удар:** `fill-opacity` 0 → 1, `scale 1 → 1.08 → 1` (`transform-origin: center`), лише **один раз** (не по колу).
4. Якщо сторінка ще вантажиться після 1,8 с — тиша: лише смужка росте; серце **не** пульсує безкінечно (спокійно, не «гральний автомат»).
5. **Прогрес смужки** — чесний: `document.fonts.ready` + картинки першого екрана (`loading="eager"` / `fetchpriority="high"`, `img.decode()`); поки подій немає — повільно повзе до 30 %. Плавно (300 ms).
6. **Зникнення:** усе готове (або `window.load`, або 4 с) → смужка до 100 % → 200 ms → увесь loader `opacity 0` + монограма `scale .96` за 400 ms → видалити з DOM, `html` повертає прокрутку.
   Якщо сторінка готова раніше, ніж завершилась промальовка, — дочекатися кінця кроку 3 (не обривати на півслові), але не довше 1,8 с від появи.

## C · Підключення

- `BaseLayout.astro`: скрипт loader-а — **першим** у `<body>`, модуль < 3 КБ, без залежностей. Поки loader видно — `html.is-loading { overflow: hidden }`.

## Перевірка

- DevTools → Network → «Slow 3G» + вимкнений кеш: K промальовується, заповнюється, серце — один удар, смужка доходить до 100 %, плавне зникнення.
- Звичайний інтернет — loader-а немає. Друга сторінка в сесії — без нього. Зменшений рух — статичний логотип + смужка. Без JS — звичайна сторінка.
- Lighthouse: LCP не погіршився. Немає помилок CSP, `npm run build` зелений.
