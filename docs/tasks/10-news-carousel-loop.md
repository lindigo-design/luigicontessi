## Що треба

1. **Зациклити.** Після останньої картки йде перша, перед першою — остання. Стрілки і свайп працюють
   нескінченно в обидва боки, без «стіни» на краях і без різкого перемотування назад через усю стрічку.
2. **Висота секції не стрибає.** Зараз при зміні активної картки висота залежить від довжини опису
   (1 рядок, 2 рядки або опису немає) → усе, що нижче, смикається. Висота має бути однаковою для будь-якої картки.

## 1. Безкінечна стрічка

Підхід — **клони з тихим перескоком** (працює і зі свайпом, і з `scroll-snap`):

- Справжні картки: N штук із контенту. Перед ними — копії останніх 2, після них — копії перших 2
  (на mobile видно ±1, на desktop ±2 сусіди — копій достатньо, щоб краї ніколи не були порожніми).
- Копії — лише візуальні: `aria-hidden="true"`, `inert`, посилання всередині з `tabindex="-1"`;
  читалка і Tab бачать тільки N справжніх.
- Активна картка — завжди по центру екрана (як зараз).
- Коли після прокрутки/свайпу активною стає **копія**, скрипт одразу, **без анімації**
  (`scrollTo({ behavior: 'auto' })`), переставляє стрічку на відповідну **справжню** картку.
  Різниці на око не видно, бо копія і оригінал однакові.
- Індекс завжди за модулем: `next = (i + 1) % N`, `prev = (i - 1 + N) % N`.
- Крапки (mobile) показують позицію **справжньої** картки (1…N).
- Під час «тихого перескоку» тимчасово вимикати `scroll-snap-type` і `transition` на картках,
  потім повертати в наступному `requestAnimationFrame` — інакше браузер може смикнути стрічку.
- Клавіатура: ← / → коли фокус у каруселі; Home / End — перша / остання справжня.
- `prefers-reduced-motion`: прокрутка без плавності, решта так само.
- Якщо карток менше 3 — не зациклювати і сховати стрілки.

## 2. Стабільна висота

Висота секції = висота **активної** картки (фото 560 × 680 на desktop + текстовий блок).
Фото вже фіксоване через `aspect-ratio`, тому стабілізуємо **текстовий блок**:

- Обгорнути тег / назву / опис / «Voir» у `.ncard__info`.
- **Опис активної картки — рівно 2 рядки місця** (Text/Body S 14/20 → 40 px):
  ```css
  .ncard__desc {
    min-height: calc(2 * 1.43em); /* місце під 2 рядки є завжди, навіть якщо опис короткий */
    display: -webkit-box;
    -webkit-line-clamp: 2; /* довший опис — обрізається трьома крапками */
    -webkit-box-orient: vertical;
    overflow: hidden;
  }
  ```
  Якщо в товару **немає** опису — блок опису все одно рендериться порожнім з тією ж висотою
  (`<p class="ncard__desc" aria-hidden="true"></p>`), щоб кнопка «Voir» стояла на тому ж місці.
- Назва — 1 рядок (`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`), повна назва — у `title`.
- Малі картки опис не показують (як зараз), але їхній `.ncard__info` теж не впливає на висоту:
  трек вирівняний по верху (`align-items: flex-start`), висоту задає тільки активна.
- Додатково на сам трек — `min-height`, рівний висоті активної картки (з `aspect-ratio`
  ширини активної + фіксованої висоти `.ncard__info`), щоб у момент переходу між картками
  (одна ще росте, інша зменшується) висота не «дихала».
- Обмеження довжини опису в Keystatic і Zod: **≤ 110 знаків** (~2 рядки на 560 px), щоб обрізання
  траплялось рідко. Підказка в полі: «Опис для великої картки, до 2 рядків».
