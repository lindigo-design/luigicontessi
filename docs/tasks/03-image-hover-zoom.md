# Завдання 03 · Легкий зум фото при наведенні на картку (як у Bugatti)

Прочитай CLAUDE.md. Один етап: зроби лише це, потім звіт і стоп.

## Як це зроблено на bugatti.com (перевірено в браузері)

- Наводиш мишку на **всю картку** (не лише на фото) — фото всередині плавно збільшується до **105 %**.
- Тривалість **300 ms**, крива `cubic-bezier(0.4, 0, 0.2, 1)`, анімується лише `transform`.
- Рамка фото не змінюється: фото росте всередині, зайве обрізається (`overflow: hidden`).

## Правило для нашого сайту

Зум — це підказка «сюди можна натиснути». Тому:

- **Так:** лише фото всередині клікабельних карток і рядків (посилання).
- **Ні:** декоративні фото і фони — портрет у «À propos», фото біля FAQ, фони hero / Quote / Yachts /
  «Pour les marques». Якщо зум буде на всьому, він перестане щось означати.

## Кроки

### 1. Токени (src/styles/tokens.css)

```css
--zoom-scale: 1.05;
--zoom-dur: 300ms;
--zoom-ease: cubic-bezier(0.4, 0, 0.2, 1);
```

### 2. Спільний клас (src/styles/components.css)

Один клас на весь сайт, щоб ефект скрізь був однаковий:

- `.media` (рамка фото) уже має `overflow: hidden` і `border-radius` — лишити.
- `.zoom-card` — ставиться на посилання/картку.
- Правило: `.zoom-card .media img { transition: transform var(--zoom-dur) var(--zoom-ease); }`
- Зум лише на пристроях з мишкою:
  ```css
  @media (hover: hover) and (pointer: fine) {
    .zoom-card:hover .media img,
    .zoom-card:focus-visible .media img {
      transform: scale(var(--zoom-scale));
    }
  }
  ```
  `:focus-visible` — щоб людина з клавіатурою теж бачила, яка картка вибрана.
- `prefers-reduced-motion: reduce` → `transition: none; transform: none`.
- `will-change` НЕ ставити постійно (зайва памʼять); браузер сам впорається з `transform`.

### 3. Де застосувати (додати клас `zoom-card` і прибрати локальні дублікати)

| Секція                     | Файл                  | Елемент                                                                                |
| -------------------------- | --------------------- | -------------------------------------------------------------------------------------- |
| Hero — дві маленькі картки | home/Hero.astro       | `.hcard`                                                                               |
| Nouveautés — усі картки    | home/News.astro       | `li.ncard` (посилання — фото + кнопка «Voir»)                                          |
| Univers — мініатюри рядків | home/Universes.astro  | `.urow` (разом з наявним білим/сірим станом)                                           |
| La collection              | home/Collection.astro | `.product a` — **прибрати** локальний `scale(1.03)` / 600ms, замінити на спільний клас |
| Instagram                  | home/Instagram.astro  | кожне фото стрічки                                                                     |

Для майбутніх сторінок (Journal, Coups de cœur, Yachts, Card/Article, Card/Yacht) — той самий клас,
нічого нового не вигадувати.

### 4. Разом із зумом (так виглядає цілісно)

- При наведенні на картку коло-стрілка в ній заливається червоним (як уже працює на `Button variant="accent"`):
  додати правило `.zoom-card:hover .arrow { background: var(--color-red-text); color: var(--color-bg); }`.
- Більше нічого не рухати: без підйому картки, без тіней, без зміни яскравості фото.

## Що НЕ чіпати

- Розміри карток, відступи, тексти.
- Фони секцій і декоративні фото (див. «Ні» вище).

## Перевірка

1. `npm run format`, `npm run build` — без помилок.
2. Desktop 1440: наведення на кожну картку з таблиці — фото плавно росте до 105 % за 0.3 с,
   рамка і текст не зсуваються, сусідні картки не «стрибають».
3. Tab з клавіатури по картках — той самий ефект.
4. Mobile 390 (touch): зуму немає, нічого не «залипає» після натискання.
5. «Зменшити рух» увімкнено — зуму немає.
6. Звіт: що зроблено + список файлів. Стоп.
