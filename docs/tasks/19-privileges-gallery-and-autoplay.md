- Обгортка — `container` (ті самі бокові відступи, що в секцій вище), відступ знизу 96 (на 768–1023 — 64), зверху 0
  (над блоком і так є нижній відступ «Tous les codes»).
- Сітка: `grid-template-columns: minmax(0, 2fr) minmax(0, 1fr) minmax(0, 1fr)`, проміжок 24, `align-items: start`.
  - велике фото: `aspect-ratio: 628 / 680`;
  - два малі: `aspect-ratio: 302 / 418`, **притиснуті до верху** (низ правої частини порожній — так задумано).
- Радіус 4 (як `Image Placeholder`), `object-fit: cover`, центр кадру; без затемнення, без підписів.
- Не посилання → без зуму при наведенні.
- `<Image widths=[600, 900, 1400, 1800]` для великого, `[400, 600, 900, 1200]` для малих; `sizes` — від реальної ширини колонки
  (`(min-width: 768px) 44vw, 80vw` і `(min-width: 768px) 21vw, 80vw`). `loading="lazy"`.

### Mobile < 768 — невелика карусель

- Стрічка з 3 фото, **свайп пальцем** (`overflow-x: auto; scroll-snap-type: x mandatory`, скролбар прихований).
- Слайд — 80 % ширини екрана, `aspect-ratio: 3 / 4`, проміжок 12, відступ зліва 16 (як у контейнера).
  Наступне фото виглядає справа — видно, що можна гортати.
- Під стрічкою крапки 6 px по центру (як у «Nouveautés»), проміжок 8; активна — `--color-text`, інші — `--color-border`.
  Крапки — `<button aria-label="Photo 2 sur 3">` (тексти через `t()` у трьох мовах), клік → плавно до фото.
- **Автопрокрутка** кожні 5 с по колу (після 3-го — назад на 1-ше), правила — див. блок «Автопрокрутка» нижче.

## B · Головна, «La collection»: вищі малі фото

Щоб на обох сторінках була одна логіка (велике фото + два вертикальні), на **desktop ≥ 1024** малі картки
«Chemise Blanche» і «Chaussures Contessi» стають вертикальними, як у Privilèges:

- `Collection.astro`: у `@media (min-width: 1024px)` малим фото замість `aspect-ratio: 1` → **`302 / 418`**.
- Велике фото не змінюємо (`628 / 642`). Малі картки — притиснуті до верху (вже так).
- Перевір: підписи (назва + «[Prix]») під малими фото не зʼїжджають, на 1024 назва не обрізається некрасиво.
- `sizes` для малих — без змін. Mobile/tablet < 1024 — без змін.

## C · «Nouveautés»: свайп + автопрокрутка (головне — tablet 768–1023)

Зараз на tablet стрілок немає, а крапки не клікаються. Мишкою стрічку не потягнеш — незрозуміло, як гортати.

1. **Свайп пальцем** — уже працює (scroll-snap), не ламати.
2. **Перетягування мишкою** на ширині < 1024 (`pointerType === 'mouse'`): тягнеш — стрічка їде за курсором,
   відпустив — `setActive` на найближчу до центру картку. Під час перетягування `cursor: grabbing`,
   клік по посиланню картки **не спрацьовує**, якщо мишку зрушили > 6 px.
3. **Крапки клікаються**: `<li>` → `<button aria-label="Slide 2 / 5">`, клік → відповідна справжня картка
   (не копія). Зніми `aria-hidden` з `<ol>`. Зона кліку ≥ 24×24 (крапка 6 px + прозорий padding).
4. **Автопрокрутка** кожні 5 с вперед по колу — **на всіх ширинах** (на desktop теж, стрілки лишаються).

## Автопрокрутка — спільні правила (A і C)

Зроби один маленький модуль `src/scripts/autoplay.ts`: `createAutoplay(root, next, { delay: 5000 })`,
повертає `{ restart, stop }`. Правила:

- Пауза, коли: курсор над блоком, фокус усередині (`focusin`/`focusout`), блок не видно на екрані
  (`IntersectionObserver`, threshold 0.3), вкладка прихована (`visibilitychange`).
- Людина сама погортала (свайп, перетягування, стрілка, крапка, клавіша) → відлік 5 с починається **заново**.
  Палець на екрані (`pointerdown` / `touchstart`) → пауза до `pointerup` / `touchend`.
- `prefers-reduced-motion: reduce` → автопрокрутки **немає зовсім** (лише руками).
- Таймер — `setTimeout`, не `setInterval`; без inline-стилів (CSP).
- Для «Nouveautés» автопрокрутка = `step(1)` (з тим самим тихим перескоком з копії, що вже є).
- Для галереї — лише на < 768 (на ширших екранах каруселі немає: `matchMedia` + слухати зміну).
- Читалці екрану автопрокрутка нічого не оголошує (без `aria-live`).

## Перевірка

- Privilèges на 390 / 768 / 1024 / 1440 / 1920: на ≥ 768 — три фото як у Figma, рука і коробка не обрізані;
  на 390 — карусель, свайп, крапки, сама гортає кожні 5 с і зупиняється, коли тримаєш палець.
- Головна, La collection, 1440: малі фото вертикальні 302 × 418, підписи на місці.
- Nouveautés на 900 px (tablet) у звичайному браузері: тягну мишкою — гортається; клік по крапці — переходить;
  стою і не чіпаю — гортається сам; навів курсор — стоїть.
- Увімкнений «зменшений рух» у системі — нічого не гортається само.
- Немає горизонтальної прокрутки сторінки, немає помилок CSP, `npm run build` зелений.
