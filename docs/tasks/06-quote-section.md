## Що змінилось у Figma (виміряно в файлі)

|                             | Figma desktop 1440                                                                 | Зараз у коді                          |
| --------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------- |
| Висота секції               | **738 px** (фіксована), картка по центру по вертикалі                              | ≈ 604 px (лише відступи 160 + картка) |
| Кадр фото                   | видно смугу з літаком і червоною Lamborghini — центр кадру на **59 %** висоти фото | `object-position: 50% 58%`            |
| Міжрядковий інтервал цитати | Desktop/Quote 36/46, Mobile/Quote 24/32                                            | `line-height: 1.3` для обох           |

Mobile (390): висота 388 px = 96 + картка + 96 — у коді вже так, не чіпати. Кадр mobile — центр фото (50 % 50 %).
Картка без змін: 880 px max, відступи 72 (desktop) / 32 (mobile), проміжок 32 / 20, радіус 4, фон bg/base.

## Що змінити

1. **Висота desktop:** на `.quote` додати `min-height: clamp(24.25rem, 16.125rem + 33.333vw, 46.125rem); /* 388 → 738 */`
   і вирівняти картку по центру: `display: grid; place-items: center;` (або flex з `align-items: center`).
   Відступи `padding-block` лишити — вони потрібні, коли цитата довша (EN/IT) і не влазить.
2. **Кадр фото desktop:** у медіа-запиті `min-width: 1024px` замінити `object-position: 50% 58%` → `50% 59%`.
   На mobile — `object-position: 50% 50%` (нічого не дописувати, це значення за замовчуванням).
3. **Міжрядковий інтервал:** `blockquote p { line-height: 1.333; }` (Mobile/Quote 24/32),
   а в `@media (min-width: 1024px)` → `line-height: 1.278;` (Desktop/Quote 36/46).
4. Фото не міняти: у Figma той самий файл (`quote.jpg`, хеш dcb991f8…).

## Що НЕ чіпати

- Тексти цитати й автора (FR/EN/IT).
- Картку (ширина, відступи, кольори), шрифти.
- Інші секції.
