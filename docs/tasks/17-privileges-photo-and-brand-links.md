Прочитай CLAUDE.md. Дві частини — після кожної `npm run format`, `npm run build`, звіт, стоп.

## Частина 1 · Фото на всю ширину (`PhotoBreak.astro`)

**Проблема.** Висота зараз обмежена 749 px (`clamp(… 46.8125rem)`), а ширина росте до 1920 / 2560.
Фото розтягується в ширину, кадр стає «смугою», і рука з годинником обрізається негарно.

**Нове фото:** у Figma на desktop тепер рука з годинником Golden Concept тримає білу коробку
(кадр по центру). Файл **уже замінено** в проєкті: `src/assets/img/privileges/break.jpg` (2400 px завширшки).

**Рішення — пропорція замість фіксованої висоти:**

- **≥ 1024 px:** висота росте разом із шириною в пропорції Figma `1440 × 749`:
  ```css
  .pbreak :global(img) {
    width: 100%;
    height: auto;
    aspect-ratio: 1440 / 749; /* на 1440 → 749, на 1920 → 999, на 2560 → 1332 */
    max-height: 100svh; /* не вище за вікно — фото не «з'їдає» весь екран на дуже широких */
    object-fit: cover;
    object-position: 50% 50%; /* у Figma кадр по центру (FILL) */
  }
  ```
  Так кадр однаковий на всіх широких екранах: годинник, рука і коробка — цілі, як у макеті.
- **< 1024 px:** як було — `height: clamp(26.25rem, …)` (420 px на 390), `object-position: 50% 50%`.
- Прибрати старі `object-position: 50% 69%` / `50% 61%` і медіа-запит `1680px` — вони були під попереднє фото.
- `widths={[768, 1280, 1920, 2400]}` — щоб на 2560 не розтягувалось маленьке зображення.
- Figma mobile (`125:485`) ще показує **старе** фото — у коді використовуємо нове для всіх ширин
  (Яна оновить mobile у Figma).

**Перевірка:** 1440 / 1920 / 2560 — годинник і пальці на коробці в кадрі, нічого не «відрізано»;
390 — висота 420 px.

## Частина 2 · Кнопки «Voir la marque» — завжди видимі, із заглушками

**Проблема.** У `CodeCard.astro` кнопка показується лише коли є `url`. У всіх кодів зараз `url: null`
→ на сайті (головна і Privilèges) немає жодної кнопки переходу до партнерів. Дизайн виглядає неповним,
і незрозуміло, що код треба вводити на сайті марки.

**Рішення:**

1. Кнопка **«Voir la marque →»** (Link Accent з колом) показується **завжди** — і на головній, і на Privilèges,
   і в блоці «À la une».
2. Коли `url` є — як зараз: справжнє посилання, `target="_blank"`, `rel="sponsored noopener"`, «(nouvelle fenêtre)».
3. Коли `url` ще немає — **заглушка**:
   - той самий вигляд кнопки (нічого не «сіріє», макет не ламається);
   - це `<a href="#" data-placeholder aria-disabled="true">` з `title` «Lien bientôt disponible» (i18n: EN «Link coming soon», IT «Link in arrivo»);
   - клік нічого не відкриває (`preventDefault` у спільному скрипті), а під кнопкою на 2 с з'являється
     дрібний текст «Lien bientôt disponible» (Body S, secondary) — чесно, без «битого» переходу;
   - hover — як у звичайної Link Accent (коло заливається червоним), щоб на перегляді виглядало «живим».
4. **Нагадування перед запуском:** під час `npm run build` вивести в консоль список кодів без `url`:
   `⚠ Privilèges: 10 codes sans lien marque — boutique-15, chapeaux-10, …`.
   Якщо змінна `LC_STRICT=true` (поставимо на продакшн-збірці) — збірка **падає**, щоб на живий сайт
   не потрапили заглушки. На тестовій копії GitHub Pages `LC_STRICT` не ставити.
5. Поле в Keystatic: «Сайт марки (https://…) — поки порожнє, на сайті буде заглушка».

**Що НЕ чіпати:** вигляд картки, кнопку «Copier le code», тексти пропозицій.

**Перевірка:**

1. Головна (секція Privilèges) і `/fr/privileges/`: у кожній картці є «Voir la marque →».
2. Клік по заглушці — нікуди не переходить, з'являється «Lien bientôt disponible».
3. Тимчасово впиши справжній `url` одному коду — кнопка відкриває сайт у новій вкладці.
4. `LC_STRICT=true npm run build` — збірка зупиняється зі списком кодів без посилань.
5. Звіт + список файлів. Стоп.
