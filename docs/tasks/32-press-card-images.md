## Дані

- `home.json → press.items[]` (fr / en / it): нове **необовʼязкове** поле `image` (`image()` у Zod, поле в Keystatic) + `imagePosition` (рядок, напр. `"50% 87%"`).
  - картка 1 (Presse écrite): `press-1.jpg`, `50% 87%`;
  - картка 2 (TV): `press-2.jpg`, `50% 33%`;
  - картка 3 (Podcast): `press-3.jpg`, `50% 90%`.
- Без `image` — картка як зараз, без фото (нічого не ламається). Ті самі дані використовує Partenariats → «Dans la presse» — там фото **не** показуємо.

## Вигляд (`Press.astro`, картка `pcard`)

- Порядок: верхній рядок (логотип медіа · мета) → **фото** → заголовок → цитата → кнопка (як у Figma).
- Фото на всю ширину картки (усередині її padding 28), `aspect-ratio: 355 / 139` (≈ 2.55 : 1), радіус 4, `object-fit: cover`,
  кадр — `imagePosition` (CSS-змінна через `data-` атрибут і скрипт, як у кейсах Partenariats — без inline-стилів, CSP).
- Mobile (картки в горизонтальній стрічці, ширина 300): та сама пропорція.
- `<Image widths={[360, 720, 1080]} sizes="(min-width: 1024px) 26vw, 300px" loading="lazy">`, `alt=""` — декоративне (заголовок поруч).
- Hover картки (світло за курсором, завдання 13) **плюс** легкий зум фото — клас `zoom-card` на обгортці фото (завдання 03), зум лише при наведенні на картку.
- Висоти карток у ряду однакові (як зараз): фото фіксованої пропорції, цитата займає вільне місце, кнопка внизу.

## Перевірка

- 390 / 1024 / 1440 / 1920: фото не розтягуються, кадр як у Figma (каюта, яхта, салон), картки однакової висоти.
- Картка без `image` — без порожнього місця.
- Partenariats → «Dans la presse» без змін.
- `npm run build` зелений.
