# Завдання 30 · Partenariats → «Références»: безкінечна стрічка логотипів марок

Прочитай CLAUDE.md. Після кроку `npm run format` + `npm run build`, короткий звіт і стоп.

Figma: Partenariats desktop → «05 Références» → «Logos»: тепер **один рядок** 1280 × 80 (замість сітки 6 × 2).
На сайті — **безкінечна стрічка**: логотипи найбільших марок повільно пливуть справа наліво, по колу.

## Дані

- `partenariats.json → referencesItems.logos`: `[{ name, image? }]` — `image` (SVG / PNG з прозорим фоном у `src/assets/img/logos/`) **необовʼязкове**.
- Порядок = порядок у списку (найбільші марки першими). Без обмеження 12 — до 20.
- Поки файлів логотипів немає: у **перегляді** (dev / `PUBLIC_NOINDEX=true`, як Audience і кейси) показуємо **текстові логотипи** —
  назва марки великими літерами (Manrope 500, 18 px, `letter-spacing: 0.2em`, `--color-text-2`). Список для перегляду:
  **GAC · Golden Concept · Briston · Shokz** (марки, з якими Luigi вже працює — є на сайті). На живому сайті без файлів — стрічка схована, як зараз.

## Вигляд

- Рядок висотою **80** (mobile 56), на всю ширину **контейнера** (не екрана); краї **розчиняються** — `mask-image: linear-gradient(to right, transparent, #000 8%, #000 92%, transparent)`.
- Логотип вписаний у висоту 32 (mobile 24), ширина — за пропорцією, проміжок між логотипами **64** (mobile 40).
- Колір: монохром світлий (`filter: grayscale(1) brightness(1.6)`, `opacity: .6`); при наведенні на конкретний — `opacity: 1`.
- Сірих плашок-клітинок, як у Figma-заглушці, **немає** — лише логотипи на тлі секції.

## Рух

- Чистий CSS: трек із **двох однакових наборів** логотипів (другий — `aria-hidden="true"`, без посилань у фокусі), `@keyframes` зсуває трек на `-50%`, `animation: … linear infinite`.
  Тривалість — від кількості: ~ **4 с на логотип** (4 марки → 16 с; повільно і спокійно).
- Якщо логотипів мало і один набір вужчий за контейнер — повтори набір стільки разів, щоб заповнити ширину (на збірці, без JS).
- **Пауза при наведенні** на стрічку (`animation-play-state: paused`) і при фокусі всередині.
- `prefers-reduced-motion: reduce` → без руху: один ряд по центру, `flex-wrap: wrap`.
- Без inline-стилів (CSP): тривалість — через клас-модифікатор або CSS-змінну, виставлену скриптом.

## Доступність

- Список `<ul aria-label="Marques partenaires">` (переклад у `ui/*.json`), у першому наборі `alt` = назва марки; текстові логотипи — звичайний текст.
- Логотипи не посилання (поки немає сторінок кейсів).

## Перевірка

- 390 / 1440 / 1920: стрічка рухається плавно без стрибка на стику, краї розчиняються, нічого не вилазить за контейнер.
- Наведення — пауза; зменшений рух — статичний ряд.
- Живий сайт без файлів логотипів — секції логотипів немає; кейси GAC / Golden Concept на місці.
- Немає помилок CSP, `npm run build` зелений.
